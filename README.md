# 校园二手交易平台

> 基于 Vue3 + SpringBoot + MyBatis-Plus 开发的校园二手物品交易Demo项目，面向在校学生，实现二手商品发布、商品审核、订单管理、用户管理等基础功能。

## ✨ 项目简介
校园二手交易平台是一款校园内物品流转系统，学生可以发布闲置二手物品（教材、电子产品、生活用品、运动器材等），浏览商品并下单购买；管理员后台可以对用户、商品、订单进行统一管理，商品需要后台审核通过后才能在前台展示。

### 功能预览
- **前台用户端**
    - 商品分类浏览：全部、电子产品、图书教材、生活用品、运动器材
    - 商品筛选：综合、新降价、新发布、价格、区域
    - 商品搜索功能
    - 用户中心：账号信息、我的订单、修改密码、退出登录
    - 发布二手商品
- **管理员后台**
    - 用户管理：查看用户列表，对用户进行封禁/解禁操作
    - 商品管理 & 审核：待审核商品审核通过、已上架商品下架
    - 订单管理：查看全部订单信息，展示订单号、买家、金额、订单状态

##  核心业务流程

1. 用户注册登录，发布二手商品，商品状态默认为【待审核】
2. 管理员登录后台，进入商品管理，审核商品，审核通过后商品前台可见
3. 普通用户浏览商品，下单生成订单，订单状态为待发货
4. 管理员在订单管理页面查看平台所有订单
5. 用户管理模块支持管理员封禁违规用户
